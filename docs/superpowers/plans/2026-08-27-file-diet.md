# File Diet + Consolidation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cut the repo's file/directory count substantially with zero behavior change and zero pin churn, fix the test-mirror selection bug, and collapse prompts and skills into one sectioned file each.

**Architecture:** Five tasks: (1) deletions/moves, (2) test relocation + micro-module merges + export hygiene, (3) `config/prompts.md` + loader, (4) `config/skills.md` + registry, (5) docs consolidation. Each is gate-green on its own.

**Tech Stack:** TypeScript/Node 24, node:test, vitest, Playwright; no new deps.

**Spec:** `docs/superpowers/specs/2026-08-27-file-diet-design.md`

## Global Constraints

- **No behavior change** outside the two loaders; **no assertion weakened**; every deleted test must be dead coverage (documented in the report).
- **Pins are invariants:** `promptsSha` byte-identical; all 10 goldens in `tests/server/agents/task-worker/fixtures/agent-prompts/` unchanged; every skill digest identical. Prove with a temporary equality test per loader (old layout vs new file) that is deleted once green.
- Section format for both files: `## <name>` at column 0; bodies verbatim; a body containing a column-0 `## ` line is rejected at load. Names obey `^[a-z0-9][a-z0-9-]*$`.
- Config strictness stays (unknown keys rejected) — renamed keys get clear "use X instead" errors.
- Gate per task: `npm run typecheck:all && npm run test:all`. Close: `npm run test:container` + Playwright.
- Implementers do not commit.
